# Studio imagery

The WebP photographs in this directory are AI-generated editorial illustrations created for this site refresh with OpenAI's built-in ImageGen. They are used to illustrate creative services and gallery concepts. The BDS logo and third-party gallery playback samples have separate origins.

Each prompt requested a photorealistic editorial photograph for a Nigerian creative studio, with landscape framing, warm gold highlights, inky shadows, and no typography, logos or watermarks.
